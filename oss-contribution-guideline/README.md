# OSSコントリビューションガイドラインひな形

OSSプロジェクトへのコントリビューションに関するガイドラインをひな形として公開しています。ひな形一式は templates をご参照ください。
OSSプロジェクトへ投稿する際のルール、修正提案の方法、投稿内容の取り扱いなどを定める際にカスタマイズしてご利用いただけます。  
また、皆さまからのコメントや改善提案を取り入れながら、より多くのプロジェクトで役立つガイドラインへと継続的に改善していきます。
