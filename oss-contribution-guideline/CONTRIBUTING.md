# はじめに

OSSコントリビューションガイドラインの改善提案を歓迎します。  
誤字・脱字の修正、文章の改善、内容の追加、翻訳の修正、ファイル間の整合性改善などをご提案いただけます。  
修正提案は、IssueまたはPull Requestで受け付けます。  
最終的な内容の確認、修正、バージョンアップおよび公開は管理者が行います。

## 受け付ける提案

本プロジェクトでは、以下の改善提案を受け付けています。

1. **誤字・脱字・表記の修正**
2. **文章や構成の改善**
3. **ガイドラインなど、ひな形の内容追加・修正**
4. **日本語版と英語版の翻訳・内容の修正**
5. **Markdown版とWord版の整合性改善**
6. **リンクや参照情報の追加・修正**

## 提案方法

### Issueで提案する場合

Issueは、質問や修正案を知らせるために使用します。

1. 既存のIssueやPull Requestを確認し、同じ内容や類似した提案がないか確認してください。
2. Issueを作成し、可能な範囲で以下を記載してください。

   - 対象ファイル
   - 対象箇所
   - 現在の問題点
   - 提案する修正内容
   - 修正が必要と考える理由
   - 参照資料やURL

3. 管理者が内容を確認し、必要に応じて修正・公開します。  
迅速な対応を心がけますが、対応に時間がかかる場合があります。ご了承ください。

### Pull Requestを作成する場合

Pull Requestは、提案者自身が修正した内容を提示するために使用します。

1. 既存のIssueやPull Requestを確認して同じ内容や類似した提案がないか確認してください。
2. 必要に応じてリポジトリをForkし、作業用ブランチで修正を行ってください。
3. 関連するファイルとの整合性を確認してください。
4. Pull Requestを作成し、以下を記載してください。

   - 変更の概要
   - 変更したファイル
   - 変更理由
   - 関連するIssue
   - DCOへの対応状況

5. 管理者が内容を確認し、必要に応じて修正したうえで、変更を取り込みます。

Pull Requestの内容は、管理者による確認・修正後に取り込まれる場合があります。提案者が作成した内容が、そのまま公開されるとは限りません。

## 提案内容に関する注意事項

IssueまたはPull Requestに文章、翻訳、図表その他のコンテンツを投稿する場合は、以下を確認してください。

- 投稿内容を提供するために必要な権利を有していること
- 第三者の著作権その他の権利を侵害していないこと
- 管理者が投稿内容を編集、翻訳、改変して利用できること
- 投稿内容を本リポジトリのライセンス条件に基づいて利用できること
- 機密情報、個人情報、非公開情報を含んでいないこと

投稿内容は、管理者が確認・編集したうえで、OSSコントリビューションガイドラインの改善に利用する場合があります。

上記の条件に同意できない内容は、IssueまたはPull Requestに投稿しないでください。

## 開発者原産地証明（DCO）

本プロジェクトでは、投稿された内容の権利関係を明確にするため、[開発者原産地証明（Developer Certificate of Origin: DCO）](https://developercertificate.org/)を採用しています。

DCOは、投稿者がCommitに対して、次の事項を確認する仕組みです。

- 投稿内容を作成・提供するために必要な権利を有していること
- 投稿内容が、第三者の著作権その他の権利を侵害していないこと
- 投稿内容を本プロジェクトのライセンス条件に基づいて提供すること
- 投稿内容を本プロジェクトに取り込むことに問題がないこと

DCOは、投稿内容の著作権を本プロジェクトへ譲渡するものではありません。また、DCOへの署名だけで第三者の著作物を利用できるようになるものでもありません。

第三者が作成した文章、翻訳、画像、図表などを投稿する場合は、DCOへの署名とは別に、利用に必要な許諾やライセンスを確認してください。

### Issueで提案する場合

Issueによる提案には、Commitが含まれないため、DCOへの署名は不要です。

ただし、Issueに文章や翻訳などの具体的な成果物を投稿する場合は、投稿内容を提供するために必要な権利を有していることを確認してください。
第三者が作成したコンテンツを投稿する場合は、利用条件や出典を明記してください。

### Pull Requestを作成する場合

Pull Requestに含まれるすべてのCommitには、DCOへの同意を示す以下の署名を付けてください。

```text
Signed-off-by: 氏名 <メールアドレス>
```

Commitを作成する際に`-s`オプションを付けると、署名を自動的に追加できます。

```bash
git commit -s -m "docs: improve contribution guidelines"
```

Pull Requestの作成後、すべてのCommitに`Signed-off-by`が付いていることを確認してください。

```bash
git log --format="%h %s%n%b" origin/main..HEAD
```

署名の付いていないCommitがある場合は、Commitを修正するか、署名を付けたCommitを作成してください。

DCOの詳細については、以下を参照してください。

- [開発者原産地証明（DCO）公式サイト](https://developercertificate.org/)
- [DCO日本語参考訳](https://developercertificate.opensource.jp/)
