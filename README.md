# OSPO Templates
English version: [README_EN.md](./README_EN.md)

## 概要

本リポジトリでは、OSS（オープンソースソフトウェア）に関する当社の知見や取り組みを、社内外の皆さまに活用いただけるよう、ドキュメントを公開しています。

OSSへのコントリビューション、OSSの活用、OSSに関する学習など、さまざまな場面で役立つ情報を整理し、OSSに関わる人々がより安心して、効果的に活動できる環境づくりを目指します。

## 公開の目的

本コレクションは、以下を目的として公開しています。

- OSSを適切かつ効果的に活用するための情報を提供する
- さまざまな組織やプロジェクトで利用できる知見を蓄積する
- 皆さまからのフィードバックを取り入れ、内容を継続的に改善する

これらのドキュメントが、OSSを活用・運営する組織や、OSS活動に参加する人々の一助となれば幸いです。

## 公開ドキュメント

現在、以下のドキュメントを公開しています。

### OSSコントリビューションガイドライン

OSSプロジェクトへコントリビューションする際のガイドラインです。

OSSプロジェクトへの投稿に関するルール、修正提案の方法、投稿内容の取り扱いなどを定める際にご利用いただけます。

本ガイドラインは、当社のOSS活動で得た知見をもとに、さまざまな組織やプロジェクトで活用できるよう整理したひな形です。各プロジェクトの規模や開発体制、コミュニティの文化などに合わせて、自由に追加・変更してご利用ください。

- [OSSコントリビューションガイドライン](./oss-contribution-guideline/)

## フィードバック・コントリビューション

本コレクションは、公開して終わりではなく、皆さまからのフィードバックを取り入れながら継続的に改善していくことを目指しています。

以下のようなご意見を歓迎します。

- 内容の不足や誤りに関する指摘
- より分かりやすくするための改善提案
- 他の組織やプロジェクトでの活用事例
- OSS活動に関する知見や実践例

ご意見や改善提案がありましたら、IssueまたはPull Requestを通じてお知らせください。

## 注意事項

本リポジトリで公開しているドキュメントは、OSS活動に関して各社に共通すると思われる内容を整理したものです。
組織やプロジェクトによって適用すべきルールや運用は異なるため、実際に利用する際は、それぞれの状況に応じて内容をご確認のうえ、修正してご活用ください。

また、各ドキュメントは今後変更される可能性があります。ご利用の際は、最新版をご確認ください。
